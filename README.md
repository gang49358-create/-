# Baze China — Sneaker Store

Статический интернет-магазин кроссовок в сине-чёрной эстетике. Готов для публикации на **GitHub Pages**.

## Что работает

- Каталог из 6 демонстрационных товаров.
- Фильтры по категориям, поиск и сортировка по цене.
- Карточка товара с выбором размера.
- Добавление в корзину, изменение количества и удаление товаров.
- Корзина сохраняется в `localStorage` браузера.
- Избранное сохраняется в `localStorage`.
- Демо-оформление заказа с проверкой формы и экраном подтверждения.
- Форма подписки с локальным демонстрационным откликом.
- Адаптивный дизайн, анимации, hover-эффекты и уважение настройки `prefers-reduced-motion`.

## Запуск локально

Откройте `index.html` в браузере. Для локальной разработки также можно использовать расширение Live Server в VS Code.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub, например `baze-china`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `script.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После завершения публикации GitHub покажет адрес сайта в разделе Pages.

## Важно перед реальными продажами

Это frontend-демо, а не полноценная платёжная система. Заказы и подписки никуда не отправляются, оплата не подключена, складские остатки не проверяются. Для реального магазина потребуется backend или ecommerce-платформа, обработка заказов, политика конфиденциальности, условия возврата и безопасный платёжный провайдер.

Фотографии товаров загружаются с Unsplash по внешним URL, поэтому для стабильной публикации замените их на собственные лицензированные изображения в репозитории. Названия, цены, рейтинги и описания в каталоге — демонстрационные данные.
