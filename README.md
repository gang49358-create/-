# Baze China — Sneaker Store

Статический интернет-магазин кроссовок в сине-чёрной эстетике, готовый для GitHub Pages.

## Функции
- Каталог, фильтры, поиск и сортировка.
- Карточка товара с выбором размера.
- Корзина, изменение количества и избранное (`localStorage`).
- Демо-оформление заказа и форма подписки.
- Раздел отзывов: добавление отзыва и рейтинг.
- Раздел новостей.
- Раздел о создателях (текст-заготовка, замените на реальную информацию).
- Демо-админ-панель: добавление/удаление товаров, публикация/удаление новостей, модерация отзывов.
- Адаптивный дизайн и CSS-анимации.

## Демо-панель
Внизу сайта нажмите «Админ-панель». Демо-код: `BAZE2026`.

**Безопасность:** это frontend-демонстрация, не настоящая защищённая админка. Код доступа виден в JavaScript сайта, изменения каталога товаров не переживают перезагрузку страницы, а отзывы/новости сохраняются локально в браузере. Не используйте для управления настоящими продажами или персональными данными. Для реальной админки нужны backend, авторизация на сервере и база данных.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html`, `style.css`, `script.js`, `README.md` в корень.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.

## Перед реальными продажами
Заказы и подписки никуда не отправляются, платёжная система не подключена, складские остатки не проверяются. Используйте собственные лицензированные фотографии и добавьте политику конфиденциальности, условия доставки и возврата.
