# Baze China — магазин с Supabase

## Включено в эту сборку
- Каталог товаров загружается из Supabase; добавление/удаление доступно администратору.
- Вход администратора через Supabase Auth с проверкой `admin_users`.
- Форма заказа вызывает RPC `create_store_order`, которая считает стоимость по ценам в базе и сохраняет заказ и позиции.
- В админ-панели есть вкладка «Заказы» для просмотра заказов и изменения статуса.
- Онлайн-оплата не подключена.
- Новости, отзывы и подписка пока остаются локальными демонстрационными данными.

## Перед публикацией
1. Убедитесь, что в Supabase существуют `products`, `admin_users`, `orders`, `order_items`, а таблицы заказов защищены RLS.
2. Выполните `supabase-orders-function.sql` в Supabase SQL Editor. Он обновляет RPC-функцию создания заказа.
3. Убедитесь, что в `products` есть товары и у них заполнены `sizes` и `price`. При пустом каталоге войдите администратором, чтобы заполнить его демо-товарами.
4. Загрузите `index.html`, `style.css`, `script.js` в корень GitHub-репозитория и сделайте Commit.
5. Проверьте тестовый заказ с вымышленными контактными данными, затем удалите его при необходимости из Supabase.

## Безопасность
- В браузере используется только Supabase Publishable key. Никогда не добавляйте `service_role` или `sb_secret_` в файлы сайта.
- Не храните и не отправляйте реальные данные клиентов при тестировании.
- Перед реальным запуском добавьте политику конфиденциальности, правила доставки/возврата и защиту от спама.
