Baze China — исправленный полный script.js

Исправление: при публикации новости текст передаётся в обязательное поле Supabase news_items.content.

Установка:
1. Сделайте резервную копию текущего script.js.
2. Замените script.js в репозитории этим файлом целиком.
3. Commit changes в GitHub и дождитесь обновления GitHub Pages.
4. Откройте сайт и обновите страницу через Ctrl+F5.

Важно: архив содержит только script.js и инструкцию. Если схема Supabase или RLS настроены иначе, могут потребоваться дополнительные изменения.
