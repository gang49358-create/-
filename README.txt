# Baze China — обновление Telegram и отслеживания заказа

## Файлы сайта
Загрузите `index.html`, `style.css` и `script.js` в корень GitHub Pages, заменив старые версии.

## Важно: включить проверку статуса
1. Откройте Supabase → SQL Editor.
2. Скопируйте содержимое `baze-china-order-status.sql` и нажмите Run.
3. После этого покупатели смогут открыть блок «Где твой заказ?» и проверить статус по номеру заказа и телефону. Телефон используется для подтверждения владения заказом; публично выдаются только статус, сумма, дата и состав заказа.

## Как работает оформление
После успешного сохранения заказа сайт показывает кнопки `@dealbin` и `@klacha82`. Каждая открывает чат с подготовленным текстом, включающим номер заказа и введённые данные. Покупателю нужно самостоятельно нажать «Отправить» в Telegram.

## Проверка
Оформите тестовый заказ с вымышленными контактами, убедитесь, что он появился в Supabase `orders` и `order_items`, затем проверьте статус на сайте. Не используйте реальные данные при тестировании. Статус меняется администратором в панели магазина.
