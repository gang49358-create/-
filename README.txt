# Baze China — Telegram, статусы заказов, новости и отзывы в Supabase

## Файлы сайта
Загрузите `index.html`, `style.css` и `script.js` в корень GitHub Pages, заменив старые версии.

## SQL для базы
1. Откройте Supabase → SQL Editor.
2. Скопируйте весь файл `baze-china-content.sql` в новый запрос и нажмите Run — он подключает новости и отзывы к Supabase.
3. Если ещё не настраивали проверку статуса заказа, также выполните `baze-china-order-status.sql`.

## Новости
Администратор входит в админ-панель и открывает вкладку «Новости». Добавленные новости сохраняются в `news_items` и отображаются у всех посетителей сайта. Удаление тоже удаляет запись из Supabase.

## Отзывы
Посетители могут отправлять отзывы через форму. Они сохраняются в таблице `reviews` и затем отображаются на сайте у всех пользователей. Администратор может удалять отзывы из вкладки «Отзывы». Публичное создание отзыва разрешено; редактировать/удалять записи могут только администраторы.

## Проверка
После замены файлов нажмите Commit changes в GitHub, откройте сайт и обновите через Ctrl+F5. Добавьте тестовую новость из админ-панели и отправьте отзыв с тестовым именем. Проверьте таблицы `news_items` и `reviews` в Supabase. Не используйте реальные личные данные при тестировании.

## Заказы и Telegram
После успешного сохранения заказа сайт предлагает перейти к `@dealbin` или `@klacha82` с подготовленным текстом; покупатель должен сам нажать «Отправить» в Telegram. Статус заказа меняется администратором и читается из Supabase.
